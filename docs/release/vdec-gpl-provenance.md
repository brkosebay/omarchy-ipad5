branch was rewritten. An old message/comment is historical evidence, not the

applicable prefix with corrected mail numbering. Their `SHA256SUMS` are

Its content guard rejects old pinned refs with superseded table provenance.

## Reproduce

```sh
python3 -B scripts/vdec/fetch-table-sources.py
python3 -B scripts/vdec/h264-tables.py --compare tools/ds-video/vxd_h264_tables.h --psb scripts/vdec/upstream/pnw_H264.c
python3 -B scripts/vdec/audit-gpl-constants.py build/vdec-gpl/drivers/media/platform/apple/vxd
bash scripts/vdec/prove-gpl-objects.sh
python3 -B scripts/vdec/compare-gpl-objects.py build/vdec-gpl
TREE=vdec-gpl bash scripts/vdec/host-cmdstream.sh
TREE=vdec-gpl SMOKE_JOBS=2 bash scripts/vdec/qemu-smoke.sh build
TREE=vdec-gpl bash scripts/vdec/qemu-smoke.sh run
python3 -B scripts/vdec/export-gpl.py
python3 -B scripts/release/test_release.py
```

The audit script accepts any local copy of the driver directory. To read it
from the volume instead, use the `--run vdec-gpl` mode of
`scripts/build-kernel.sh` with `/work/scripts/vdec/audit-gpl-constants.py`
and the in-tree driver path. Build commands are long-running: background
them and poll logs.
